## 🎒 夸克背包增强

一个轻量级的 Minecraft 1.21.1 NeoForge 模组，为 Quark 的背包增加了两个实用功能：

- **可装备至饰品栏（Curios API）的“背饰”槽位** – > 不再占用胸甲栏。
- **背包内直接打开潜影盒** – > 无需再取出到物品栏更加便利。
